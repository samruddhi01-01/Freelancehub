# FreelanceHub – Freelancing Platform

FreelanceHub is a full-stack web application that connects clients with freelancers through a single platform. Clients can create projects, receive proposals, communicate with freelancers, and manage their projects, while freelancers can discover projects, submit proposals, manage their profiles, and communicate with clients.

## 🚀 Features

### 👤 Client Features

* User registration and login
* Create and manage projects
* Browse freelancer profiles
* Receive and manage proposals
* Communicate with freelancers through chat
* Track project information
* Manage profile and account details

### 💼 Freelancer Features

* Freelancer registration and login
* Create and manage freelancer profile
* Browse available projects
* Submit proposals for projects
* Manage submitted proposals
* Communicate with clients
* Track project information

### 🛠️ Admin Features

* Secure admin authentication
* Admin dashboard
* Manage users
* Manage projects
* Manage transactions
* Monitor platform activities

### 💬 Communication

* Client–freelancer messaging
* Chat inbox
* Individual chat rooms
* Project-based communication

## 🎯 Project Objective

The objective of FreelanceHub is to develop a centralized freelancing platform that simplifies collaboration between clients and freelancers. The application demonstrates full-stack web development concepts including responsive frontend development, REST API integration, authentication, database management, project management, proposals, messaging, and administrative operations.

## 🔐 Authentication

FreelanceHub uses JWT-based authentication to provide secure access to user and admin functionality. User roles are used to control access to different features of the platform.
